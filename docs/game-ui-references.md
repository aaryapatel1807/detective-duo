# Detective Duo — canonical UI references per game

Aarya's rule (13 Oct 2026): for every game, the play surface must match the most
popular real implementation of THAT game — the canonical app/site people actually
play. Noir identity lives in the FRAME only (hub, sidebar, page header, kit
chrome: ScoreHUD/TurnBanner/ResultModal/GameButton). Where a reference involves
copyrighted artwork, recreate the LAYOUT/STYLE with original CSS-drawn assets —
match the design language, never copy proprietary art files.
